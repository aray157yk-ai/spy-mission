---

## 🚀 第一步：建立 Firebase 專案（免費）

1. 前往 https://console.firebase.google.com/
2. 點「新增專案」，輸入名稱（如 spy-mission-research）
3. 進入專案後，點左側「建構 > Realtime Database」
4. 點「建立資料庫」→ 選擇測試模式（Test mode）→ 完成
5. 點左側齒輪「專案設定」→ 往下找「您的應用程式」→ 點 </> 新增網頁應用程式
6. 複製 firebaseConfig 的內容

---

## 🌐 第三步：部署網站（免費方案）

### 方案 A：GitHub Pages（最簡單）
1. 建立 GitHub 帳號，新建 repository（如 spy-mission）
2. 把 game/ 和 admin/ 資料夾上傳
3. Settings > Pages > Branch: main > Save
4. 網址會是：https://你的帳號.github.io/spy-mission/game/
5. 後台：https://你的帳號.github.io/spy-mission/admin/

### 方案 B：Netlify（也很簡單）
1. 前往 https://netlify.com/
2. 把整個資料夾拖曳到頁面上
3. 自動部署完成

## 🎮 使用流程

### 研究者操作
1. 開啟後台，確認房間碼設定
2. 給兩位受試者相同的房間碼（如 ALPHA7）
3. 受試者分別選擇角色 A 或 B
4. 研究者在後台即時觀察對話
5. 三關結束後受試者填寫覆盤問卷
6. 後台點「匯出 CSV」下載所有資料

### 受試者操作
1. 前往遊戲網址
2. 輸入探員代號（自取）
3. 輸入研究者給的房間碼
4. 選擇角色 A 或 B（兩人不同角色）
5. 等待搭檔連線後開始遊戲

---

## 📊 後台可查看的資料

- **整體統計**：總訊息數、AI介入次數、平均字數、提問次數
- **探員資料**：各玩家發言次數、平均字數、提問次數
- **發言比例**：各關卡 A/B 發言分佈長條圖
- **合作行為標記**：自動標記「提出建議/同意/疑問/讓步」出現頻率
- **完整對話紀錄**：可按關卡篩選，含時間戳記
- **覆盤問卷**：三題反思問答全文
- **匯出 CSV**：訊息紀錄、覆盤問卷各一份
